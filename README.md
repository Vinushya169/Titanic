# Titanic Survival Prediction

This project predicts which passengers survived the Titanic disaster using Machine Learning.

### 📁 Files in this Repo
- titanic.csv - Dataset (from Kaggle)
- titanic1.ipynb - Main code with EDA and Model

### 🛠️ Tech Used
Python, Pandas, NumPy, Matplotlib, Seaborn, Scikit-Learn

### 🔍 What I Did
- Cleaned data (handled missing Age values)
- Did Exploratory Data Analysis (EDA)
- Feature Engineering
- Built Machine Learning Model - Random Forest
- Accuracy ~ 80%

### ▶️ How to Run
Open titanic1.ipynb in Google Colab or Jupyter and run all cells.
